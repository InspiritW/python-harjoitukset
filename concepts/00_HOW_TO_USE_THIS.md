# How this folder is organized (and how to actually use it)

## The folders
- `moduuliX/` = the graded exercises for module X. Each file is ONE
  exercise, with step-by-step comments instead of a wall of text.
  No answers — just the steps, so you write the actual code.
- `project/` = your one ongoing game project, built up across several
  checkpoints (Project 1-5 in the course).
- `concepts/` = this folder. One file per NEW idea, in the order you'll
  meet it. Each one has: a plain explanation, a small working example
  you can run as-is, and a "your turn" prompt at the bottom with no
  answer — just something to try or think about.

## Suggested order
Concepts are numbered to match when they show up in the modules. Read
concept 03 (while loops) roughly when you start module 5, etc. You
don't have to front-load all of them — that's the opposite of the point.

## A few tips that actually work for ADHD / autistic brains learning to code
(based on general ADHD/autism study-strategy guidance — see sources below)

- **One file, one task.** That's why every exercise here is its own
  file — less to hold in your head at once, less scrolling to lose
  your place in.
- **Externalize the steps.** Don't trust working memory to hold "what
  do I do next" — that's exactly what the numbered comments are for.
  Cross steps off as you go if that helps (literally delete the
  comment line once it's done, or put an x by it).
- **Timebox it.** Pick a small chunk (e.g. "just get input() working"),
  set a timer (15-25 min), take a real break after. Long unstructured
  "just sit and code" sessions are where ADHD brains struggle most —
  a visible timer + a defined stopping point makes starting easier.
- **Run the code constantly.** Don't write 20 lines then test — write
  2-3, run it, see it work (or fail), repeat. Frequent concrete
  feedback beats "get it perfect then run it once."
- **Body doubling helps.** Working alongside someone else (even just
  quietly, on a call or in the same room) can make starting and
  sticking with a task much easier — this is a well-documented ADHD
  strategy, not a crutch.
- **Predictability reduces friction.** That's why every exercise file
  here follows the exact same comment structure — once you know the
  shape, you spend your energy on the actual problem, not on figuring
  out what's being asked.
- **Special interests are fuel, not a distraction.** If a concept
  clicks better when you tie it to something you're already into
  (games, trains, whatever), do that — rewrite an example using your
  own theme if it helps it stick.
